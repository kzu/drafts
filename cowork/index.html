Cowork

Four ways to find, run and schedule tasks

Cowork lets people add tasks from a marketplace, run them by hand or on a schedule, and use whatever screen each task brings with it. The four mockups below are the same app with the same sample task, organised four different ways. Each one is clickable: filter the marketplace, install, start a run and watch its steps advance.

The same in all four

Shared decisions

  • One sample task, Invoice Intake, with five steps. Step 4 needs the person, so every run pauses there.
  • A screen that the task brings sits under a caption naming the task. The app draws everything else.
  • The task's screens are real UI SDK web components. They come without styles, so Cowork's stylesheet gives them the app's look. The bar above each concept switches to a look the task ships itself.
  • At the review step the task fills in the decisions it would make, through UI SDK's agent bridge. Cowork outlines what the task filled in, can undo it, and lists what the task may do on that screen. The button that files the invoices is marked as needing a person, so the task cannot press it.
  • Green means running or done, amber means it is waiting for you, red means it failed.
  • A run that starts on its own uses answers saved for the task's start screen.
  • Screens are snapshots, not one continuous session: the marketplace shows Invoice Intake as not yet installed.

Still open

  • Whether a task may ship its own styles or always gets Cowork's. UI SDK allows both.
  • A task's screen is code that runs inside Cowork, not data that Cowork draws. Where that code runs, and who checks it before it reaches the marketplace, is undecided.
  • What a scheduled run does at a step that needs you: wait and notify, hold those items, or not start at all. Every schedule screen offers the choice. With UI SDK, it is the answer Cowork gives when the task reaches a control marked as needing a person.
  • Whether the task's start screen is a step of the workflow or a form in front of it. Canvas and Thread treat it as part of the run; Shelf and Launchpad as a form.
