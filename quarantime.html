Case-sensitive uses 0-9 A-Z a-z (62 symbols), exactly like the catbag Base62.cs. Upper-case-only can't have 62 distinct symbols, so it uses 0-9 A-Z (36 symbols): the same most-significant-first positional encoding, safe where case is lost.

Definition: QuaranTime. Ticks are 100 ns, as in .NET; milliseconds, seconds and minutes truncate toward zero. Browser clocks have millisecond precision, so ticks always end in 0000.
